`delegating-github-issues` names the chat after the item the session holds: `#N <issue title>` once Work's claim wins, `Review PR #P <PR title>` and `Land PR #P <PR title>` for Review and Land, and `/delegate watching <owner>/<repo>` when a Run or Watch pass ends holding nothing, so several delegator sessions can be told apart in the Claude Code on the web sidebar, the `/resume` picker and the terminal title. In a cloud session the rename goes through the `set_session_title` tool; in the CLI it appends the `custom-title` record that `/rename` writes to the session transcript. A failed rename is reported in one line and never stops a run. The `/delegate` command pre-approves the calls.
